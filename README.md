## Overview
This project demonstrates an end-to-end Apache Airflow Directed Acyclic Graph (DAG) that automates the entire lifecycle of a Google Cloud Dataproc cluster. It creates a cluster, runs a PySpark data processing job on it, and then deletes the cluster immediately afterward.

## Project Explanation
* **Business Need:** Infrequent jobs (running once or twice a day) do not require a dedicated, always-on cluster, which wastes resources and money. This project provisions infrastructure only when needed.
* **Structure:** The pipeline processes employee data against department data to find high-earning employees and maps them to their respective departments.
* **Key Feature:** Features a self-destructing cluster mechanism using Airflow's `trigger_rule='all_done'` to guarantee the cluster is deleted regardless of whether the processing task succeeds or fails.

## Technology Stack
* **Orchestration:** Apache Airflow (Managed via Google Cloud Composer)
* **Compute/Processing:** Google Cloud Dataproc (PySpark)
* **Storage:** Google Cloud Storage (GCS)

## Architecture & Structure
* **Infrastructure Provisioning:** Airflow triggers a task to spin up a Dataproc cluster with 1 master node and 2 worker nodes.
* **Data Processing:** Airflow submits a PySpark job to the newly created cluster to filter employees earning over 50,000 and performs an inner join with department data.
* **Infrastructure Teardown:** Once the PySpark job finishes, Airflow triggers the final task to delete the cluster, preventing idle resource billing.

## Workflow
1. Upload the DAG file (`airflow_spark_job.py`) to the Airflow monitoring bucket (the `dags/` folder generated by Cloud Composer).
2. The DAG, named `employee_data_analysis_with_spark`, appears in the Airflow Web UI with `schedule_interval=None`.
3. A user manually triggers the DAG by clicking the play button.
4. **Task 1** runs, creating the cluster (visible in the GCP Dataproc UI under the "Provisioning" state).
5. **Task 2** runs, executing the PySpark script to read CSVs, filter, join, and write output back to GCS.
6. **Task 3** runs upon completion of Task 2, permanently deleting the cluster.

## Prerequisites
* **GCP Project:** Set up a Google Cloud Project (e.g., `project-d1684aga-9dde-4e3c-974`) and note the Project ID.
* **Storage Bucket Preparation:**
  * Create a GCS bucket named `airflow-test-projects-gds-dev`.
  * Inside the bucket, create the directory structure: `airflow-project-1/data/`, `airflow-project-1/spark-job/`, and `airflow-project-1/output/`.
* **Data Uploads:**
  * Upload `employee.csv` and `department.csv` to the `data/` folder.
  * Upload `emp-batch-job.py` to the `spark-job/` folder so Dataproc can fetch it during execution.

## File Descriptions
* `department.csv`: Raw data file containing `dept_id` and `dept_name` (e.g., 100, Engineering).
* `employee.csv`: Raw data file containing `emp_id`, `emp_name`, `dept_id`, and `salary` (e.g., 1, Alice, 100, 60000).
* `emp-batch-job.py`: The PySpark script responsible for data transformations and joins.
* `airflow_spark_job.py`: The Airflow DAG file containing the Dataproc operators that orchestrate the cluster lifecycle and job submission.

from pyspark.sql import SparkSession

# Define the main data processing function[cite: 3]
def process_data():
    # Initialize SparkSession[cite: 3]
    spark = SparkSession.builder.appName("GCP Dataproc Job").getOrCreate()
    
    # Define the GCS bucket name[cite: 3]
    bucket = "airflow-test-projects-gds-dev"
    
    # Define file paths dynamically using the bucket name[cite: 3]
    emp_data_path = f"gs://{bucket}/airflow-project-1/data/employee.csv"
    dept_data_path = f"gs://{bucket}/airflow-project-1/data/department.csv"
    output_path = f"gs://{bucket}/airflow-project-1/output"
    
    # Read the employee and department CSV datasets with schema inference[cite: 3]
    employee = spark.read.csv(emp_data_path, header=True, inferSchema=True)
    department = spark.read.csv(dept_data_path, header=True, inferSchema=True)
    
    # Filter employee data to include only those with a salary greater than 50000[cite: 3]
    filtered_employee = employee.filter(employee.salary > 50000)
    
    # Join the filtered employee dataset with the department dataset[cite: 3]
    # Performs an inner join on the common column "dept_id"[cite: 3]
    joined_data = filtered_employee.join(department, "dept_id", "inner")
    
    # Write the output data back to GCS[cite: 3]
    # Uses overwrite mode to ensure repeated runs do not fail[cite: 3]
    joined_data.write.csv(output_path, mode="overwrite", header=True)
    
    # Stop the Spark session[cite: 3]
    spark.stop()

# Main function execution[cite: 3]
if __name__ == "__main__":
    # Call the processing function defined above[cite: 3]
    process_data()
